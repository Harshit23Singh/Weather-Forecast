# Gram Mausam AI - Telemetry & API Data Dictionary

| Variable Key | Standard Name | Units | Description |
|---|---|---|---|
| `temperature_2m` | Ambient Air Temperature | °C | Air temperature at 2 meters above ground |
| `relative_humidity_2m`| Relative Humidity | % | Atmospheric water vapor saturation percentage |
| `surface_pressure` | Surface Pressure | hPa | Local barometric air pressure |
| `precipitation` | Precipitation Rate | mm | Liquid precipitation accumulated |
| `et0_fao_evapotranspiration` | Reference ETo | mm/day | FAO-56 Penman-Monteith grass reference evapotranspiration |
| `soil_temperature_0cm` | Surface Soil Temp | °C | Temperature at topsoil surface |
| `soil_moisture_0_to_1cm`| Volumetric Soil Moisture | m³/m³ | Volumetric fraction of water in topsoil layer |
| `wind_speed_10m` | Wind Velocity | km/h | Mean wind speed at 10 meters height |
| `wind_direction_10m` | Wind Heading | degrees | 0-360° meteorological wind vector |
| `uv_index` | Solar UV Index | index | Solar ultraviolet radiation index |
| `gdd` | Growing Degree Days | GDD | Accumulated stage-specific thermal units |
| `swdi` | Soil Water Deficit Index| index | -10 (extreme drought) to +2 (waterlogged) |
