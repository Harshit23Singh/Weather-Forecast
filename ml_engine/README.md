# Gram Mausam AI - Machine Learning Engine

Physics-Informed Deep Learning (PINN) and Agro-Climatic Intelligence Core.

## Structure

- `models/`: PyTorch PINN UNet downscaling architectures and spatial interpolators.
- `physics/`: FAO-56 Penman-Monteith reference evapotranspiration and solar radiation equations.
- `pipelines/`: Synthetic ERA5 data generators, downscaling trainers, and ICAR pest classifier training.
- `notebooks/`: Interactive Jupyter exploration and validation notebooks.
