# Gram Mausam AI - CLI Tool

Command-line interface for automated batch processing, cron automation, and offline agro-climatic report generation.

## Usage

```bash
# Run batch 1km micro-grid downscale for Barabanki district
python cli/mausam_cli.py --district Barabanki --crop Wheat

# Run batch for Ludhiana / Basmati Rice
python cli/mausam_cli.py --district Ludhiana --crop Paddy
```
